# [Search element in Vector](https://www.geeksforgeeks.org/problems/search-in-vector/1?page=3&category=STL)
## Easy
Given a vector arr[] with non-negative integers arranged in increasing order and an integer k. You need to check whether the element k is present or not in vector by applying binary search on it.
Examples:
Input: arr[] = [2, 3, 4, 5, 6], k = 6Output: trueExplanation: 6 is present on the 4rth index.
Input: arr[] = [2, 3, 4, 6], k = 5Output: falseExplanation: 5 is not present in arr[].
Constraints:1 ≤ arr.size() ≤&nbsp;10001 ≤ arr[i] ≤ 10001 ≤ k ≤&nbsp;1000
